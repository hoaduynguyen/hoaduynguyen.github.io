# Portfolio của Nguyễn Duy Hòa

Dự án Portfolio chứa thông tin cá nhân, học vấn và quá trình công tác của tôi.

## Cấu trúc thư mục

- `css/`: Chứa file style.css định dạng giao diện
- `js/`: Chứa các script tương tác (nếu có)
- `index.html`: Trang web chính
- `.github/`: Cấu hình github (workflows, issue templates...)
